# CASCADE — формальная верификация математики модели старения центриолей (Lean 4)

**Модель:** CASCADE (*Counter-based Asymmetric Stem-Cell Aging: Division Counters & Entropy Export*) —
модель организменного старения. **Файл:** `CASCADE.lean` (папка `CASCADE/lean/`) — компилируется `lake env lean CASCADE.lean`, **0 ошибок, 0 warnings**.
**Модель:** рукопись Tqemaladze (модель геометрического старения центриолей, в подготовке;
препринт-подача — preprints.org), `L_{n+1} = α·L_n + (1-α)·L_0 + μ + ε_n`, α ≈ 0.97.
⚠️ Это НЕ публикация на bioRxiv (статей на bioRxiv нет).

## Доказано машинно (namespace `Cascade`)
| Утверждение модели | Теорема в Lean |
|---|---|
| Closed form длины | `length_closed_form`: `L_n = L₀ + μ(1-αⁿ)/(1-α)` |
| Closed form дисперсии | `variance_closed_form`: `Var(L_n) = σ²(1-(α²)ⁿ)/(1-α²)` |
| Приращение дисперсии | `variance_succ_sub`: `Var(L_{n+1}) − Var(L_n) = σ²·(α²)ⁿ` |
| Приращение длины | `length_succ_sub`: `L_{n+1} − L_n = μ·αⁿ` |
| **Персистентность** (нет релаксации к норме) | `variance_mono`: дисперсия не убывает по n |
| **Accumulation / counter function** (геометрия считает деления) | `length_drift_strict_mono`: при μ>0, α>0 длина строго растёт с делением |
| **Конечное равновесие (mean)** | `length_tendsto`: `L_n → L₀ + μ/(1-α)` |
| **Конечное равновесие (variance)** | `variance_tendsto`: `Var(L_n) → σ²/(1-α²)` |

## Пять счётчиков делений (дополнение к `CASCADE_Core.lean`)

Каждый из 5 счётчиков модели формализован **отдельной теоремой** (namespace `Cascade`,
файл `CASCADE_Core.lean`, раздел 5). Рекуррентности в Lean соответствуют коду `rust/src/main.rs`
(`Params::base()` и цикл `run()`):

| # | Счётчик (Rust) | Рекуррентность (Lean) | Теоремы |
|---|---|---|---|
| 1 | Центриоль `S_c` (d_c=0.6, k_c=30) | `S_c(n+1)=S_c(n)+d_c` | `centriole_closed_form`, `centriole_strict_mono` |
| 2 | Теломеры `T` (τ=1.0, t_min=10) | `T(n+1)=T(n)−τ` | `telomere_closed_form`, `telomere_strict_anti` |
| 3 | mtDNA `M` (d_m=0.5, k_m=25) | `M(n+1)=M(n)+d_m` | `mtDNA_closed_form`, `mtDNA_strict_mono` |
| 4 | Протеостаз `P` (d_p=0.4, r_p=0.05, k_p=8) | `P(n+1)=P(n)+d_p−r_p·P(n)` (= reservoir c=r_p) | `proteostasis_closed_form/mono/tendsto/no_exit` |
| 5 | Эпигенетический `E` (e_drift=0.4, k_e=25) | `E(n+1)=E(n)+e` | `epigenetic_closed_form/strict_mono/exists_exit`, `epigeneticExitTime_spec/min` |

Ключевые машинно доказанные факты:
- **Эпигенетический счётчик считает деления**: `E(n)=e·n`; при `e>0` строго монотонен и
  рано или поздно превысит любой порог (`epigenetic_exists_exit`).
- **Время выхода** `n*` — первый шаг с `E(n*)>k_e` — существует и минимально
  (`epigeneticExitTime_spec/min`). Для параметров по умолчанию `n* = 63` (проверено примером).
  Значение e_drift=0.4 разведено с mtDNA (d_m=0.5, n*=51): эпигенетика = поздний/вторичный счётчик.
- **Протеостаз — «счётчик с оборотом»**: сходится к `d_p/r_p`; при `d_p/r_p ≤ k_p` порог
  никогда не пробивается (`proteostasis_no_exit`) — с дефолтами `0.4/0.05 = 8 = k_p` (граница).
- **Параметры по умолчанию проверены примерами**: `S_c(50)=30=k_c`, `T(90)=10=t_min`,
  `M(50)=25=k_m`, `E(50)=20`, `E(63)=25.2>k_e`.

## Взаимодействия счётчиков и экспорт энтропии (секции 6–7 `CASCADE_Core.lean`)

**Секция 6 — синергия (cross-coupling, литература):** mtDNA/ROS → теломеры (von Zglinicki 2002,
PMID 12114022), теломеры → mtDNA (Sahin 2011, PMID 21307849), теломеры → эпигенетика,
эпигенетика → протеостаз, протеостаз → mtDNA (López-Otín 2013/2023, PMID 23746838/36599349).
Все коэффициенты связи неотрицательны → счётчики остаются монотонными (`telomereCoupled_anti`,
`mtDNACoupled_mono`) и связь только ускоряет выход (`telomereCoupled_le_standalone`,
`mtDNACoupled_ge_standalone`). В дефолтном прогоне синергия ускоряет истощение ~на 17%
(counter-only), и «эмерджентным победителем» становится протеостаз — эпигенетический дрейф
ломает его граничное равновесие (d_p/r_p = k_p).

**Секция 7 — экспорт энтропии (сегрегация молекул между дочерними клетками):** ядровая
рекуррентность `reservoir` — это сегрегация: `a` = доля старых молекул, уходящих в сиблинг.
Задерживающая «молодая» линия `R(n+1)=(1−a)R(n)+d` ограничена и сходится к `d/a`
(`retained_tendsto`), при `a=0` (экспорта нет) превращается в неограниченный линейный счётчик
(`retained_no_export_equals_counter`), сиблинг — монотонно накапливающий сток (`sibling_mono`),
больше асимметрия → чище задерживающая линия (`retained_eq_antitone`). Литература: Katajisto
2015 (PMID 25837514), Aguilaniu 2003 (PMID 12610228), Rujano 2006, Erjavec 2007, Loeffler 2019,
Moore 2015. Режимы «где экспорт не происходит»: пост-митотические клетки, необновляемые
единицы (центриоль), провал сегрегации a→0, коллапс f(S), потеря протеостаза/митофагии,
самообновляющийся «сток» (рак).
