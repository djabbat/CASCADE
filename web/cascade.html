Formalism

Five division counters run in parallel; the first to pass its threshold sets replicative capacity (any-of exit):

τ_eff = (telomerase ON) ? 0 : τ + c_tm·m_load·o2
M(n+1) = M(n) + d_m + c_mt·tel_fail + c_mp·proto_load
P(n+1) = P(n) + d_p − (r_p − c_pe·epi_load)·P(n)
E(n+1) = E(n) + e_drift + c_et·tel_fail

Couplings (all ≥ 0) encode literature-grounded interactions (ROS→telomere, telomere→mtDNA p53/PGC-1α, telomere→epigenetic, epigenetic→proteostasis, proteostasis→mtDNA/mitophagy). Non-negative couplings can only accelerate exit (Lean: firstCross_le_of_dominated).

Entropy export — the foundation

Asymmetric segregation of old/damaged molecules between daughter cells is the entropy export: the retained “young” lineage R(n+1) = (1−a)·R(n) + d stays bounded (equilibrium d/a) while a > 0; the sibling is the entropy sink. At a = 0 (no export) the retained lineage becomes the unbounded linear aging counter. The non-dilutable centriole cannot be exported — it is the universal counter even in telomerase-positive stem cells.
