# NO_EXPORT_MODES.md — где экспорт энтропии НЕ происходит (каталог по рукописям корпуса)

> CASCADE: **экспорт энтропии = фундамент модели**. Сегрегация молекул между дочерними
> клетками = экспорт: задерживающая «молодая» линия `R(n+1) = (1−a)·R(n) + d` (a = доля
> старых молекул, уходящих в сиблинг). Пока `a > 0` — линия ограничена (равновесие `d/a`,
> Lean: `retained_tendsto`); при `a = 0` (экспорта нет) — неограниченный линейный счётчик
> (Lean: `retained_no_export_equals_counter`). **Старение = где экспорт не происходит.**
>
> Это каталог: каждый из 6 режимов «нет экспорта» раскрыт через рукописи корпуса
> (`~/Desktop/Services/publications/`). Пути — относительные, от корня `publications/`.

## Шесть режимов «нет экспорта» (= старение)

| # | Режим | Суть | Lean / раздел |
|---|---|---|---|
| 1 | Пост-митотические клетки | нет деления → только внутриклеточный экспорт `r_intra` | раздел (I), `regime_b_days` |
| 2 | Необновляемые единицы (центриоль) | не экспортируется/не заменяется → `S_c` неограничен | `centriole_strict_mono`, (C) |
| 3 | Провал сегрегации `a→0` | задерживающая линия держит всё → reservoir → счётчик | `retained_no_export_equals_counter` |
| 4 | Коллапс `f(S)→f_min` | при высоком S сам экспорт перестаёт работать | `export_strictAnti`, (H) |
| 5 | Потеря внутриклеточного экспорта | протеостаз/митофагия (связь эпигенетика→протеостаз) | `proteostasis_no_exit`, (J) |
| 6 | Самообновляющийся «сток» (рак) | дочь с повреждениями не дифференцируется/не умирает | (K) |

## Вывод для модели
Режимы 1–6 — это конкретные контексты, в которых **асимметричный экспорт энтропии
отсутствует или проваливается**. Рукописи корпуса покрывают каждый режим и дают:
(а) механизмы (центриолярный шаблон — режим 2; сегрегация митохондрий/агрегатов — режим 3;
абортивный ре-вход нейронов — режим 1+2), (б) количественные демонстрации (NPEG — режимы 1/3),
(в) falsifiable дизайны для проверки. Модель CASCADE формализует общий механизм
(`retainedDaughter`/`siblingDaughter`), а каждая рукопись — его частный случай.

> Синхронизация: при обновлении рукописей корпуса обновлять эту карту (режим → рукопись → тезис).
